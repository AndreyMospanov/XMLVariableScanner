# XML Variable Scanner

Windows-приложение для потокового поиска технических переменных в больших наборах XML-файлов.

## Возможности

- параллельная обработка XML без загрузки файлов целиком в память;
- быстрый текстовый и XML-aware режимы чтения;
- XML-комментарии пропускаются в обоих режимах;
- простые маски (`*` и `?`) и профессиональные регулярные выражения .NET;
- несколько масок исключения, игнорирование регистра по умолчанию;
- потоковая запись фильтруемого XLSX-отчёта;
- автоматическое продолжение на новом листе при достижении лимита строк Excel;
- отдельные листы ошибок и параметров запуска;
- технический UTF-8 журнал рядом с отчётом;
- прогресс и безопасная отмена операции.

Основные столбцы отчёта: `Переменная | Имя файла | Относительный путь | Строка`.

## Режимы чтения

- **Быстрый текстовый** — ищет во всех частях XML, кроме комментариев. Это самый быстрый и наиболее терпимый к некорректному XML вариант.
- **С учётом структуры XML** — ищет в тексте, CDATA и значениях атрибутов, пропуская комментарии, имена тегов, декларации и processing instructions.

## Маски

В простом режиме `*` означает любое количество символов переменной, а `?` — один символ. Например, `$$P_*`. Знак `%` является обычным символом.

В профессиональном режиме используется Regex .NET. Всё совпадение становится переменной; чтобы вернуть только часть совпадения, следует использовать именованную группу `(?<variable>...)`.

## Сборка и запуск

Требуется .NET 10 SDK для разработки. В корне репозитория:

```powershell
dotnet restore XmlVariableScanner.slnx --configfile NuGet.Config
dotnet build XmlVariableScanner.slnx
dotnet run --project src\XmlVariableScanner.Desktop\XmlVariableScanner.Desktop.csproj
```

Проверки:

```powershell
dotnet run --project tests\XmlVariableScanner.Tests\XmlVariableScanner.Tests.csproj
```

## Ограничение Excel

Excel допускает не более 32 767 символов в одной ячейке. Более длинная физическая строка XML помечается и обрезается до этого лимита; количество таких строк указывается в техническом журнале и на листе `О запуске`.
